# 자료 상태와 사용 제한 (persona-accuracy)

이 폴더 파일의 출처·이용 조건 표는 저장소 루트의 `data/SOURCES.md`에 있습니다. 아래는 각 기록을 읽을 때의 제한입니다.

NVIDIA Nemotron-Personas-Korea는 CC BY 4.0 합성 인물 자료입니다. 원본 패널과 profile은 변경하지 않았고 속성 배정도 수행하지 않았습니다.

사회조사 5개 표는 저장소 baseline_official.json의 역사적 출처 목록입니다. raw_sha256은 이 로컬 파일의 바이트 해시이며 API 원응답 확보를 뜻하지 않습니다. 원문·조사 기간·이용 조건 재확인 전 모두 unverified로 빌드에서 제외합니다. 기존 baseline.json은 legacy이며 ‘과거 5개 진단 문항, 비교 정의 제한 있음’으로만 해석합니다.

인구표의 정확한 ID, MDIS 코드북·개인 연결·가중치·재배포 허용은 미확인입니다. 확인되지 않은 ID나 해시를 만들지 않으므로 sources 목록에 가짜 항목을 추가하지 않았습니다. reference와 mapping은 빈 비활성 계약입니다. 가구 점유율을 개인에게 배정하지 않습니다. 신규 holdout은 0개이며 독립 평가·서비스 활성화는 불가합니다.

공공 원자료·MDIS 개인 행은 포함하지 않습니다. 허용된 집계만 로컬 가져오기 대상으로 하며 MDIS 다운로드 자동화는 없습니다.
