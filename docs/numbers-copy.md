# 결과 첫 화면의 숫자 문구

결과 맨 위에 합성 인물 규모와 찬반 비율을 먼저 보여 줍니다. 모든 숫자는 실제 여론이 아니라 먼저 찾아갈 집단과 질문을 고르는 방향 참고값으로 읽히게 씁니다.

- 숫자는 엔진 집계(`overall`·`by_group`·`highlights`·`baseline`·`slice_results`)에서만 나옵니다. 모델이 쓴 문장에는 지금처럼 숫자를 넣지 않습니다(`public_rules.SYSTEM_RULES`, `check_output`는 바뀌지 않음).
- 문구는 `engine/pp/numbers_copy.py` 한 곳에 있습니다. 요약 카드(`summary_card.py`), 예시 결과 요약(`pp://examples/result-summary`), 다시 자르기 도구는 같은 함수를 씁니다.
- 기준값은 서비스 집계(`ppservice/survey/aggregate.py`)와 같습니다. 흔들림 폭 최소 3.0%p, 대조 문장 또는 선택지 순서 흔들림 7.0%p 초과 시 불안정, 비교 기준 100명입니다. 시험이 두 값을 맞춰 봅니다.

## 요약 카드 순서 (3,000자 안)

1. 모의 실행은 `trial_notice`의 체험 고지를 첫 줄에 그대로 표시한 뒤, 고정 합성 인물 배너와 보관·모의 꼬리를 표시합니다. 도구 설명도 이 필드(요약은 `summary.trial_notice`)를 참조합니다.
2. **숫자로 먼저 보기**: 고정 배너 → 규모 → 대표 패널 분포와 흔들림 폭 → (불안정 경고) → '모름' 주의 → 과거 공개 기준선 → 명단 밖 안내
3. 집단별 작은 표(마크다운): 연령대·권역·성별, 영향권 패널은 표 아래 별도 한 줄
4. 다시 자른 숫자(있을 때)와 "60대만 보면?" 안내
5. 찾아갈 곳 · 먼저 물을 질문: 카드마다 `숫자 근거:` 한 줄, 카드에 없는 강조 집단은 "숫자로 본 방문 후보"
6. 명단 밖 사람 · 빠진 관점

넘치면 이 순서로 줄입니다. 앞서 다시 자른 숫자 → 표를 연령대와 ▲ 칸만 남김 → 카드 끝부분. 숫자 줄·표 머리·방문 후보·명단 밖 사람은 남깁니다. 숫자가 있으면 문안 근거 발췌를 160자에서 60자로 줄여 보관 인용과 현장 질문의 자리를 확보합니다. 보관 예시는 실제 Jev 숫자를 포함하며 문구·표와 함께 3,000자 예산을 검사합니다.

```text
숫자로 먼저 보기(방향 참고값)
합성 인물 모의 응답(실제 사람 0명)입니다. 여론조사가 아니며, 먼저 찾아갈 집단과 질문을 고르는 참고값입니다.
규모: 합성 인물 풀 100만 명에서 AI가 5,000명의 반응을 추정(실제 조사 아님 · 판단 모델: Jev · 이유 수집: 문장 모델 400명 별도, 대표 300·영향권 100)
대표 패널 모의 분포: 찬성 쪽 47% · 반대 쪽 17% · 모름 36% (흔들림 3.8%p: 문장·순서를 바꿔 다시 물었을 때 달라진 정도 · 대조 문장 2.1%p·선택지 순서 3.8%p 중 큰 값, 최소 3.0%p)
모의 응답의 '모름' 비율은 실제 유보율과 크게 다를 수 있습니다.
과거 공개 기준선: 동일 문항 없음.
명단 밖: 19세 미만·외국인 주민·단체의 조직된 의견(맨 아래에서 따로 확인).
집단별 모의 분포(대표 패널 · ▲: 100명 이상이고 찬성·반대·모름 중 하나의 차이가 흔들림 3.8%p와 인원 비교 기준을 넘음)

| 집단 | 합성 인물 | 찬성 쪽 | 반대 쪽 | 모름 | 찬성 쪽 차이 |
|---|---:|---:|---:|---:|---:|
| 60대 | 893명 | 39% | 27% | 34% | -8%p ▲ |
| 제주 | 65명 | 58% | 10% | 32% | +11%p 표본 여유 부족 |
| 울릉 | 4명 | 1명 | 2명 | 1명 | 해석 불가(5명 미만) |

별도 측정 · 영향권 패널: 문장 모델 단일 선택이라 한쪽으로 쏠릴 수 있으며 위 판단 모델과 직접 비교할 수 없습니다. 이유를 적은 합성 인물 100명의 목소리 참고.
…
• 60대 · 70세 이상 · 단순노무 종사자
  숫자 근거: 60대 · 동남권 합성 인물 146명 중 반대·유보 추정 62%(전체 대비 +9%p, 흔들림 폭 초과)
```

(위 흔들림 폭·영향권·지역 줄은 시험용 값입니다. 보관 예시에는 흔들림 폭 기록이 없어 "흔들림 폭 미측정: 집단 차이를 강조하지 않음"으로 나옵니다.)

## 숫자 표현 문구

| 자리 | 문구(`numbers_copy`) |
|---|---|
| 고정 배너 `BANNER` | 합성 인물 모의 응답(실제 사람 0명)입니다. 여론조사가 아니며, 먼저 찾아갈 집단과 질문을 고르는 참고값입니다. |
| 꼬리 `TAILS` | 보관: 미리 실행한 보관 결과(0원 열람)입니다… / 문장 모델 대체: 판단 모델 없이 문장 모델 소표본(N명)으로 대체한 결과입니다… / 모의: 화면 구조 확인용 가짜 숫자(0원 체험)입니다… |
| 규모 `SCALE` | 규모: 합성 인물 풀 100만 명에서 AI가 N명의 반응을 추정(실제 조사 아님 · 판단 모델: Jev · 이유 수집: 문장 모델 M명 별도, 대표·영향권) |
| 분포 `DIST` | 대표 패널 모의 분포: 찬성 쪽 X% · 반대 쪽 Y% · 모름 Z% (흔들림 W%p: 문장·순서를 바꿔 다시 물었을 때 달라진 정도, 최소 3.0%p) |
| 흔들림 미측정 | (흔들림 폭 미측정: 집단 차이를 강조하지 않음) |
| 불안정 `UNSTABLE` | 불안정: 대조 문장이나 선택지 순서만 바꿔도 결과가 흔들립니다. 이 문항의 숫자는 방향 참고로 쓰기 어렵습니다… |
| 기준선 `BASELINE` | 과거 공개 기준선(참고): 찬성 54% … [2024 통계청 사회조사 · 직전값 · 모델 호출 0회]. 과거 공개 집계의 추세이며, 현재 여론이나 합성 응답의 정답이 아닙니다. |
| 영향권 `AFFECTED` | 별도 측정 · 영향권 패널: 문장 모델 단일 선택·쏠림 주의, 이유를 적은 합성 인물 N명의 목소리 |
| 숫자 근거 `BASIS` | 숫자 근거: {집단} 합성 인물 N명 중 반대·유보 추정 X%(전체 대비 +Dp, 흔들림 폭 초과) |
| 다시 자르기 `SLICE` | [대표 패널] 60대: 합성 인물 893명 중 찬성 쪽 39% · … (전체 대비 찬성 쪽 -8%p) (흔들림 3.8%p) |
| 이유 `SLICE_REASONS` | 이유(문장 모델 표본 N명 중 이 조건, AI가 상상한 문장이며 실제 사람의 말이 아님): … |

백분율은 반올림해 세 값의 합을 100으로 맞춥니다. 0.1% 미만은 `<0.1%`, 99.9% 초과는 `>99.9%`, 1% 미만과 99% 초과는 소수 한 자리로 써서 소수 의견을 0%나 100%로 지우지 않습니다.

## 소집단 4단계 (표·다시 자르기 공통)

| 칸 인원 | 표기 | 동작 |
|---|---|---|
| 5명 미만 | 인원만(`4명 중 찬성 쪽 1명 · 반대·유보 3명`) | 해석 불가 표시, 강조·방문 근거 제외 |
| 5~29명 | 인원 먼저 + 비율(`18명 중 찬성 쪽 7명(39%)`) | 소집단 주의 |
| 30~99명 | 비율 | 흔들림 폭을 넘어도 ▲ 대신 "표본 여유 부족" |
| 100명 이상 | 비율 | 찬성·반대·모름 중 한 차이가 전체·집단 흔들림과 인원 비교 기준을 함께 넘으면 ▲ |

인원 기준은 실제 숫자 칸의 분모에 적용합니다. 별도 이유 소표본이 적다고 893명·600명 숫자 칸에 "표본 여유 부족"을 붙이지 않습니다. 이유에는 "이유 표본 N명: 문장 모델의 목소리 참고로만"을 붙이고, 비율 없는 영향권 목소리 안내에는 숫자 칸 경고를 붙이지 않습니다.

불안정(대조 문장 또는 순서 흔들림 7.0%p 초과)이거나 흔들림 폭이 없으면 방문 근거를 만들지 않습니다. 대표 패널과 영향권 패널을 합친 값은 만들 수 없고, 다른 패널 이름은 오류로 거절합니다. 학력·소득 경고 문구는 해당 축을 지원하는 향후 경로용이며, 현재 빠른 재집계에서는 학력·소득 조건을 지원하지 않습니다.

## 쓰면 안 되는 표현 (`numbers_copy.FORBIDDEN`)

| 규칙 | 이유 | 대신 |
|---|---|---|
| `survey` | 실제 사람에게 물은 조사가 아닙니다. (국민 여론, 민심, 민의, 여론조사 결과, 응답자) | 합성 인물 모의 응답, 모의 패널 기준 |
| `definite` | 실측한 사실처럼 읽힙니다. (나타났다, 조사됐다, 드러났다, 확인됐다) | ~로 추정됐다, 현장 확인이 필요하다 |
| `generalize` | 합성 속성을 현실 집단 전체로 넓힙니다. (대다수, 대부분, 과반, 시민들은 찬성) | 60대 합성 인물 N명 중 반대·유보 추정 X% |
| `real_subject` | 숫자의 주어가 실제 사람처럼 읽힙니다. (국민의 47%가 찬성, 60대의 62%) | 합성 인물 N명 중 찬성 쪽 X% |
| `sampling_error` | 확률표본의 오차가 아니라 모델 흔들림입니다. (95% 신뢰수준, 표본오차, 통계적으로 유의) | 흔들림 X%p(문장·순서를 바꿔 다시 물었을 때 달라진 정도) |
| `rate_rank` | 조사 비율·순위·자격 판정처럼 읽힙니다. (찬성률, 지지율, 1위, 수급 대상 확정) | 찬성 쪽 X%, 모의 추정치(제도 자격과 무관) |
| `panel_mix` | 비대표 영향권 패널을 전체 분포에 섞습니다. (대표 5,000 + 영향권 400) | 대표 패널 기준 X% / 영향권 N명 별도 |
| `tiny_percent` | 5명 미만 칸에 비율을 붙입니다. (4명 중 3명(75%)) | 4명 중 반대·유보 3명(비율 숨김) |
| `borrowed_error` | 다른 조사의 오차를 이 문항의 오차처럼 붙입니다. (Pew, ±12%p) | 이 실행의 흔들림 폭만 씁니다 |
| `no_subject` | 찬반 비율 줄에 누구의 값인지(합성 인물·모의·패널·추정·기준선)가 없습니다. | 대표 패널 모의 분포: 찬성 쪽 X% |

`violations(text)`는 규칙 이름과 걸린 말을 돌려줍니다. 시험은 이 모듈이 만드는 모든 문구, 숫자 지침의 좋은 예·나쁜 예, 안내 문구의 예시 문장, README 대화 예시에 이 검사를 돌리고, 카드 문구는 출력 안전 관문(`PP_SAFETY_GATE=report`)에서도 걸림이 없는지 봅니다.

## 엔진 필드 연결

실제 계약은 `pp.run/4`이며 [numeric-result-contract.md](numeric-result-contract.md)를 따릅니다.
`numbers_copy.view()`는 다음 필드를 카드 문구용 값으로 변환합니다. 이전 평면 필드도 저장 카드 호환을 위해 읽습니다.

```text
overall       n, population, rates{support,oppose,unknown}, decision{model,fallback},
              variability{available,width_pp,control_pp,order_pp,unstable},
              reason_sample_n, reasons_by_panel, affected{n,rates}
by_group      {age_band|region|sex: [{panel,group,n,rates,delta_pp,highlight,variability}]}
highlights    [{group,n,rates,delta_pp,highlight,outreach{where,method}}]
baseline      available, probabilities, options, history_sources, method, source_name
slice_results filters, panel, n, rates, variability, reasons[{reason,source}], source_scope
```

- 대표 패널 행만 주 표에 넣고 영향권은 별도로 표시합니다.
- 강조는 엔진의 `highlight` 판정을 사용합니다. 집단·전체 흔들림과 인원 비교 기준을 함께 통과한 집단만 찾아갈 곳으로 연결합니다.
- 보관 예시는 실제 Jev 전체 확률 평균을 포함합니다. 집단별로는 저장된 `reserve`(반대·유보)와 그 나머지(찬성 쪽)까지만 표시하며 반대·모름은 따로 만들지 않습니다.
- `rates=null`인 극소 집단은 인원과 해석 불가 표시를 남깁니다. 미측정 흔들림이나 불안정한 값은 방문 근거가 되지 않습니다.

## 숫자 더 물어보기 (MCP)

- 안내 메뉴 `more_numbers`("숫자 더 물어보기")는 질문을 실제 등록된 무료 도구 `slice_results`의 `filters`로 변환합니다.
- 입력은 실행 `id` 또는 받은 전체 `result` 중 하나입니다. `filters`에 `age_band`, `region`, `province`, `sex`, `age_min`, `age_max`, `stance`, `panel`을 넣습니다.
- `stance`는 `support`·`oppose`·`unknown`, `panel`은 `representative`(기본)·`affected`입니다. 이유 수는 `reason_limit`(0~10, 기본 3)입니다.
- 도구는 `mcp_copy.TOOLS`에 등록된 문구와 `numbers_copy.slice_text()`를 사용해 고정 `text`를 제공합니다. 도구가 없는 구형 환경만 `get_run(view="full")`의 집단표로 대체합니다.
- 재집계의 흔들림은 해당 집단에서 다시 계산합니다. 보관 결과는 저장 집단표와 같은 조건이면 그 Jev 행을 먼저 보여 줍니다. 표에 없는 축(시도 포함)과 조건은 숫자 없이 모의(0원) 실행 또는 직접 실행으로 안내합니다. 이유 소표본은 목소리만 보여 주고 문장 모델 쏠림을 알립니다. 같은 지명이라도 시도 강원과 권역 강원을 구분해 표시하며, 잘못된 권역값은 유효한 권역 목록으로 안내합니다.
