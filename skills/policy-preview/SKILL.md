# 백번 미리 묻다 — 첫 3분

처음 사용할 때 먼저 이렇게 안내하세요.

> 처음엔 키 없이 무료 예시를 보세요. 숫자 카드와 “60대만 보면?”까지 0원입니다. 내 문안은 예상 비용과 시간을 확인하고 동의한 뒤 실행합니다.

도구 이름의 접두사는 호스트마다 다릅니다. 현재 발견된 policy-preview MCP 도구를 사용하세요. 도구가 없다면 플러그인을 설치한 뒤 새 대화를 열도록 안내하고, 결과를 만들어 내지 마세요. pip 설치나 절대 경로 설정을 사용자에게 시키지 마세요. 실행기는 플러그인이 준비합니다.

## 무료 예시 → 숫자 카드 → 다시 묻기

1. `check_setup`으로 준비 상태를 확인하세요. 키·패널이 없어도 무료 예시를 진행할 수 있습니다. `ready=false`를 무료 예시의 실패로 해석하지 마세요.
2. 사용자가 무료 예시를 요청하면 `try_example`을 `example="subway-free-ride"`로 호출하세요. 새 모델 실행 없이 보관된 공개 예시를 읽습니다. 다른 예시는 도구가 돌려주는 목록에서 고릅니다.
3. 반환된 숫자 카드와 고지·출처를 전달하고, 먼저 만날 집단과 물을 질문을 짧게 설명하세요. **합성 인물의 모의 반응이며 실제 사람 응답은 0명**입니다. 실제 여론·지지율·자격 판정으로 표현하지 마세요. 보관 결과이고 비용이 0원임을 알리세요. 없는 흔들림 폭이나 통계를 만들지 마세요.
4. “60대만 보면?”에는 같은 세션의 반환 `id`와 `filters={"age_band":"60대"}`를 `slice_results`에 넣으세요. 받은 표와 근거만 설명하고 재집계 비용·모델 호출이 0임을 알리세요. `estimate`의 `plan_id`는 실행 `id`가 아닙니다. 서버 재시작으로 결과가 사라지면 무료 예시를 다시 읽으세요.

## 내 문안은 비용 확인부터

공개·가상 문안만 받으세요. 비공개 문안·개인정보를 입력하도록 유도하지 마세요. `estimate`로 예상 비용·시간·규모·상한을 제시하고 유료 실행 동의를 받으세요. 승인된 조건의 `plan_id`로만 `start_run`을 부르고 `get_run`으로 결과를 확인하세요. 조건이 바뀌면 재견적합니다. 키가 없으면 무료 예시를 계속 쓸 수 있고, 실제 실행의 키·패널 준비는 README의 선택 설정을 안내하세요. 키를 대화나 도구 인자에 받지 마세요.

세부 사용 안내는 MCP `pp://guide/start`와 내장 prompts를 읽으세요. 숫자 표현은 도구가 주는 고지와 한계를 그대로 따릅니다. 이 스킬은 엔진 MCP 연결 안내입니다. 별도 경량판의 정책 검토 절차는 [policy-preview-lite v1.0.0](https://github.com/hosungseo/policy-preview-lite/tree/v1.0.0)을 참고하며 여기 복제하지 않습니다.
